# Pathfinder

File-based dynamic Express router with composable middleware. Drop route files into a folder and they're registered automatically, with no manual `app.get(...)` wiring.

## Guides

- [Getting started](./getting-started.md): install, create a server, add your first route
- [Routing](./routing.md): how file paths map to URLs, the route file shape, per-route middleware
- [Middleware](./middleware.md): body parsing
- [Authentication](./auth.md): bearer tokens and HMAC-signed webhooks, including replay protection
- [Errors](./errors.md): throwing HTTP errors and what the built-in error handler sends back
- [API reference](./api.md): every export and its options
